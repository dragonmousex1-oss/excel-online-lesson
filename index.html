บทที่ 1

รู้จักกับ Microsoft Excel

วัตถุประสงค์: นักเรียนสามารถอธิบายส่วนประกอบของ Excel และเริ่มต้นใช้งานได้

📌 Excel คืออะไร?

Microsoft Excel เป็นโปรแกรมสเปรดชีต (Spreadsheet) ที่ใช้ในการจัดการข้อมูลในรูปแบบตาราง คำนวณ วิเคราะห์ข้อมูล และสร้างกราฟ เป็นหนึ่งในโปรแกรมที่ใช้กันแพร่หลายมากที่สุดในโลก ทั้งในสถานศึกษาและที่ทำงาน

💡 ทำไมต้องเรียน Excel?

  • ใช้ในการเรียน: คำนวณคะแนน จัดตารางสอบ ทำรายงาน
  • ใช้ในชีวิตประจำวัน: จัดการรายรับ-รายจ่าย วางแผนงาน
  • ใช้ในอนาคต: เป็นทักษะสำคัญในการทำงานทุกสาขาอาชีพ

📌 ส่วนประกอบหลักของ Excel

ส่วนประกอบ คำอธิบาย ตัวอย่างการใช้งาน
Workbook ไฟล์ Excel ทั้งหมด (สมุดงาน) ไฟล์ "คะแนนสอบ.xlsx"
Worksheet แผ่นงานแต่ละแผ่น (Sheet) Sheet1: คะแนนเทอม 1
Cell เซลล์ (ช่องตัดกันของแถวและคอลัมน์) เซลล์ A1, B2, C3
Row แถว (แนวนอน ใช้ตัวเลข) แถวที่ 1, 2, 3...
Column คอลัมน์ (แนวตั้ง ใช้ตัวอักษร) คอลัมน์ A, B, C...
Formula Bar แถบสูตร สำหรับพิมพ์สูตรคำนวณ =SUM(A1:A10)
Ribbon แถบเครื่องมือด้านบน แท็บ Home, Insert, Data

กด Ctrl+S หรือ File → Save As → เลือกที่เก็บ → ตั้งชื่อไฟล์ → Save

บทที่ 2

การจัดการข้อมูลใน Excel

วัตถุประสงค์: นักเรียนสามารถป้อนข้อมูล จัดรูปแบบ และจัดการข้อมูลใน Excel ได้

📌 ชนิดของข้อมูลใน Excel

Excel สามารถรับข้อมูลได้หลายชนิด ซึ่งจะส่งผลต่อการคำนวณและการแสดงผล

ชนิดข้อมูล คำอธิบาย ตัวอย่าง การจัดตำแหน่ง
ตัวเลข (Number) ข้อมูลที่เป็นตัวเลข สามารถนำมาคำนวณได้ 100, 3.14, -5 ชิดขวา
ข้อความ (Text) ข้อมูลที่เป็นตัวอักษร ไม่สามารถคำนวณได้ สมชาย, Hello ชิดซ้าย
วันที่ (Date) ข้อมูลวันที่ เวลา 1/1/2025, 10:30 AM ชิดขวา
สูตร (Formula) สูตรคำนวณ ขึ้นต้นด้วย = =A1+B1, =SUM(A1:A5) แสดงผลลัพธ์

📌 การป้อนข้อมูลและแก้ไข

🔑 เทคนิคการป้อนข้อมูล

  • Enter: ยืนยันข้อมูลและเลื่อนลงแถวถัดไป
  • Tab: ยืนยันข้อมูลและเลื่อนไปคอลัมน์ถัดไป
  • Esc: ยกเลิกการป้อนข้อมูล
  • F2: แก้ไขข้อมูลในเซลล์ที่เลือก
  • Delete: ลบข้อมูลในเซลล์ที่เลือก

📌 การจัดรูปแบบข้อมูล (Formatting)

การจัดรูปแบบช่วยให้ข้อมูลดูสวยงาม อ่านง่าย และเป็นมืออาชีพ

🎨 จัดรูปแบบตัวอักษร

  • เปลี่ยนฟอนต์ ขนาด สี
  • ตัวหนา เอียง ขีดเส้นใต้
  • เลือกเซลล์ → แท็บ Home → กลุ่ม Font

📐 จัดตำแหน่ง

  • ชิดซ้าย กลาง ชิดขวา
  • Merge & Center (รวมเซลล์)
  • Wrap Text (ตัดข้อความให้อยู่ในเซลล์)

🔢 จัดรูปแบบตัวเลข

  • ทศนิยม: 3.14
  • เปอร์เซ็นต์: 85%
  • สกุลเงิน: ฿1,000.00

🖼️ เส้นขอบและสี

  • ใส่เส้นขอบ (Borders)
  • เติมสีพื้นหลัง (Fill Color)
  • Conditional Formatting

📌 การเรียงลำดับและกรองข้อมูล

การเรียงลำดับ (Sort)

ใช้สำหรับจัดเรียงข้อมูลตามลำดับ

  • A → Z: เรียงจากน้อยไปมาก
  • Z → A: เรียงจากมากไปน้อย
  • ไปที่ แท็บ Data → Sort

การกรองข้อมูล (Filter)

ใช้สำหรับแสดงเฉพาะข้อมูลที่ต้องการ

  • ไปที่ แท็บ Data → Filter
  • คลิกลูกศรที่หัวคอลัมน์
  • เลือกเงื่อนไขที่ต้องการกรอง

💻 ตัวอย่างการใช้งาน: ตารางคะแนนสอบ

A B C D
1 ลำดับ ชื่อ-สกุล คะแนนสอบ เกรด
2 1 สมชาย ใจดี 85 A
3 2 สมหญิง รักเรียน 72 B
4 3 มานะ ตั้งใจ 91 A

บทที่ 3

สูตรและฟังก์ชันใน Excel

วัตถุประสงค์: นักเรียนสามารถใช้สูตรคำนวณพื้นฐานและฟังก์ชันที่สำคัญได้

📌 หลักการเขียนสูตรใน Excel

🔑 กฎสำคัญ

  • สูตรทุกสูตรต้องขึ้นต้นด้วยเครื่องหมาย = (เท่ากับ)
  • สามารถอ้างอิงเซลล์อื่นได้ เช่น =A1+B1
  • ใช้เครื่องหมายคำนวณ: + (บวก), - (ลบ), * (คูณ), / (หาร)
  • ลำดับการคำนวณ: วงเล็บ → คูณ/หาร → บวก/ลบ

📌 เครื่องหมายคำนวณ (Operators)

เครื่องหมาย ความหมาย ตัวอย่าง ผลลัพธ์
+ บวก =5+3 8
- ลบ =10-4 6
* คูณ =6*7 42
/ หาร =20/4 5
^ ยกกำลัง =2^3 8
& ต่อข้อความ ="สวัสดี"&"ครับ" สวัสดีครับ

📌 ฟังก์ชันที่ใช้บ่อย

SUM
หาผลรวม
=SUM(ช่วงเซลล์)
ตัวอย่าง: =SUM(A1:A10)
หาผลรวมของเซลล์ A1 ถึง A10
AVERAGE
หาค่าเฉลี่ย
=AVERAGE(ช่วงเซลล์)
ตัวอย่าง: =AVERAGE(B1:B5)
หาค่าเฉลี่ยของเซลล์ B1 ถึง B5
MAX
หาค่าสูงสุด
=MAX(ช่วงเซลล์)
ตัวอย่าง: =MAX(C1:C20)
หาค่าสูงสุดจากเซลล์ C1 ถึง C20
MIN
หาค่าต่ำสุด
=MIN(ช่วงเซลล์)
ตัวอย่าง: =MIN(C1:C20)
หาค่าต่ำสุดจากเซลล์ C1 ถึง C20
COUNT
นับจำนวนเซลล์ที่มีตัวเลข
=COUNT(ช่วงเซลล์)
ตัวอย่าง: =COUNT(A1:A50)
นับจำนวนเซลล์ที่มีข้อมูลตัวเลข
IF
เงื่อนไข ถ้า...แล้ว...
=IF(เงื่อนไข, ค่าถ้าจริง, ค่าถ้าเท็จ)
ตัวอย่าง: =IF(A1>=50,"ผ่าน","ไม่ผ่าน")
ถ้า A1 ≥ 50 แสดง "ผ่าน" ไม่งั้นแสดง "ไม่ผ่าน"
COUNTIF
นับจำนวนตามเงื่อนไข
=COUNTIF(ช่วง, เงื่อนไข)
ตัวอย่าง: =COUNTIF(B1:B20,"A")
นับจำนวนเซลล์ที่มีค่า "A"
VLOOKUP
ค้นหาข้อมูลในตาราง
=VLOOKUP(ค่าค้น, ตาราง, คอลัมน์, ประเภท)
ตัวอย่าง: =VLOOKUP(A1,D1:E10,2,FALSE)
ค้นหาค่า A1 ในตาราง D1:E10 แสดงค่าคอลัมน์ที่ 2

💻 ตัวอย่าง: คำนวณคะแนนสอบกลางภาค

ABCDE
1 ชื่อ วิชา 1 วิชา 2 รวม เฉลี่ย
2 สมชาย 80 75 =B2+C2 =AVERAGE(B2:C2)
3 สมหญิง 90 85 =B3+C3 =AVERAGE(B3:C3)
4 สูงสุด =MAX(B2:B3) =MAX(C2:C3)

บทที่ 4

การสร้างกราฟและแผนภูมิ

วัตถุประสงค์: นักเรียนสามารถเลือกชนิดกราฟที่เหมาะสมและสร้างกราฟจากข้อมูลได้

📌 ทำไมต้องสร้างกราฟ?

กราฟช่วยแปลงข้อมูลตัวเลขที่ซับซ้อนให้เป็นภาพที่เข้าใจง่าย ช่วยในการวิเคราะห์ เปรียบเทียบ และนำเสนอข้อมูลได้อย่างมีประสิทธิภาพ

💡 ประโยชน์ของกราฟ

  • เห็นแนวโน้มของข้อมูลได้ชัดเจน
  • เปรียบเทียบข้อมูลได้ง่าย
  • นำเสนอข้อมูลได้น่าสนใจกว่าตาราง
  • ช่วยตัดสินใจจากข้อมูล

📌 ชนิดของกราฟที่ใช้บ่อย

📊

กราฟแท่ง (Bar/Column Chart)

ใช้เมื่อ: ต้องการเปรียบเทียบข้อมูลแต่ละรายการ

ตัวอย่าง: เปรียบเทียบคะแนนสอบแต่ละวิชา

📈

กราฟเส้น (Line Chart)

ใช้เมื่อ: ต้องการแสดงแนวโน้มที่เปลี่ยนแปลงตามเวลา

ตัวอย่าง: คะแนนสอบที่เปลี่ยนแปลงในแต่ละเดือน

🥧

กราฟวงกลม (Pie Chart)

ใช้เมื่อ: ต้องการแสดงสัดส่วนของข้อมูลรวม

ตัวอย่าง: สัดส่วนเกรดของนักเรียนในชั้น

📉

กราฟพื้นที่ (Area Chart)

ใช้เมื่อ: ต้องการเน้นปริมาณที่เปลี่ยนแปลง

ตัวอย่าง: จำนวนนักเรียนที่เข้าเรียนแต่ละสัปดาห์

📌 ขั้นตอนการสร้างกราฟ

1

เตรียมข้อมูล

จัดข้อมูลเป็นตาราง มีหัวคอลัมน์ชัดเจน ไม่มีแถวว่างคั่น

2

เลือกข้อมูล

ลากเลือก (Drag) ข้อมูลทั้งหมดที่ต้องการสร้างกราฟ รวมถึงหัวคอลัมน์

3

เลือกชนิดกราฟ

ไปที่แท็บ Insert → เลือกชนิดกราฟที่เหมาะสม (Column, Line, Pie, etc.)

4

ปรับแต่งกราฟ

ใส่ชื่อกราฟ, ปรับสี, เพิ่ม Label, จัดตำแหน่ง Legend

📌 การปรับแต่งกราฟ (Chart Elements)

องค์ประกอบ คำอธิบาย วิธีปรับ
Chart Title ชื่อกราฟ คลิกที่ชื่อ → พิมพ์แก้ไข
Axis Labels ชื่อแกน X และ Y Chart Elements (+) → Axis Titles
Legend คำอธิบายสัญลักษณ์ Chart Elements (+) → Legend
Data Labels แสดงค่าตัวเลขบนกราฟ Chart Elements (+) → Data Labels
Gridlines เส้นตาราง Chart Elements (+) → Gridlines

บทที่ 5

การประยุกต์ใช้ Excel กับการเรียน

วัตถุประสงค์: นักเรียนสามารถนำความรู้ Excel ไปใช้ในชีวิตการเรียนจริงได้

📌 โปรเจกต์ที่ 1: ตารางบันทึกคะแนนสอบ

สร้างตารางบันทึกคะแนนสอบทุกวิชา พร้อมคำนวณค่าเฉลี่ยและเกรดอัตโนมัติ

ขั้นตอนการทำ:

  1. สร้างตารางพร้อมหัวคอลัมน์: วิชา, คะแนนเต็ม, คะแนนที่ได้, เปอร์เซ็นต์, เกรด
  2. ป้อนข้อมูลวิชาและคะแนน
  3. ใช้สูตร =C2/B2*100 คำนวณเปอร์เซ็นต์
  4. ใช้ฟังก์ชัน IF ซ้อนกันเพื่อตัดเกรด:
=IF(D2>=80,"A",IF(D2>=70,"B",IF(D2>=60,"C",IF(D2>=50,"D","F"))))

ถ้าเปอร์เซ็นต์ ≥ 80 = A, ≥ 70 = B, ≥ 60 = C, ≥ 50 = D, ต่ำกว่า 50 = F

📌 โปรเจกต์ที่ 2: ตารางเวลาเรียน (Schedule)

ออกแบบตารางเรียนประจำสัปดาห์ที่สวยงามและใช้งานได้จริง

เทคนิคที่ใช้:

  • Merge & Center: รวมเซลล์สำหรับหัวตาราง
  • Fill Color: ใช้สีแยกแต่ละวิชา
  • Borders: ใส่เส้นขอบให้ตาราง
  • Conditional Formatting: เน้นวิชาที่มีสอบ
  • Print Area: กำหนดพื้นที่พิมพ์เป็น A4

📌 โปรเจกต์ที่ 3: บันทึกรายรับ-รายจ่าย

สร้างระบบบันทึกการเงินส่วนตัว ช่วยวางแผนการใช้จ่ายอย่างมีระเบียบ

สูตรที่ใช้:

=SUM(C2:C31) รวมรายรับทั้งเดือน
=SUM(D2:D31) รวมรายจ่ายทั้งเดือน
=E1-D2 คงเหลือ (ยอดสะสม)
=SUMIF(B:B,"อาหาร",D:D) รวมรายจ่ายหมวด "อาหาร"

📌 โปรเจกต์ที่ 4: วิเคราะห์ผลการเรียนด้วยกราฟ

สร้างกราฟเปรียบเทียบคะแนนสอบแต่ละวิชา เพื่อวิเคราะห์จุดแข็ง-จุดอ่อน

สิ่งที่จะได้เรียนรู้:

  • สร้างกราฟแท่งเปรียบเทียบคะแนนแต่ละวิชา
  • สร้างกราฟเส้นแสดงพัฒนาการของคะแนน
  • สร้างกราฟวงกลมแสดงสัดส่วนเวลาเรียนแต่ละวิชา
  • ปรับแต่งกราฟให้สวยงามเพื่อใส่ในรายงาน

📌 โปรเจกต์ที่ 5: แบบฟอร์มรายงานวิจัย

ออกแบบแบบฟอร์มสำหรับเก็บข้อมูลวิจัย (สำหรับวิชาโครงงาน IS)

เทคนิคขั้นสูง:

  • Data Validation: สร้าง Dropdown list เพื่อจำกัดตัวเลือก
  • COUNTIF: นับจำนวนคำตอบแต่ละตัวเลือก
  • กราฟ: สร้างกราฟสรุปผลสำรวจ
  • Print Layout: จัดหน้าสำหรับพิมพ์ส่งอาจารย์
