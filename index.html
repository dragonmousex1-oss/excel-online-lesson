Excel คืออะไร?

Microsoft Excel เป็นโปรแกรม Spreadsheet (สเปรดชีต) ที่ใช้ในการจัดการข้อมูลในรูปแบบตาราง คำนวณ วิเคราะห์ข้อมูล และสร้างกราฟ

📌
คำว่า Spreadsheet มาจาก Spread (กระจาย) + Sheet (แผ่น) หมายถึงแผ่นกระดาษที่มีข้อมูลกระจายเป็นตาราง เหมือนกระดาษตารางที่เราใช้ในวิชาคณิตศาสตร์

Excel เป็นหนึ่งในโปรแกรมที่ใช้กันแพร่หลายมากที่สุดในโลก ทั้งในสถานศึกษาและสถานที่ทำงาน มีผู้ใช้งานมากกว่า 750 ล้านคนทั่วโลก สามารถทำงานได้หลากหลาย เช่น:

🏫

ในการเรียน

  • บันทึกและคำนวณคะแนนสอบ
  • จัดทำตารางเรียน
  • ทำรายงานพร้อมกราฟ
  • วิเคราะห์ข้อมูลโครงงาน IS
🏠

ในชีวิตประจำวัน

  • จัดการรายรับ-รายจ่าย
  • วางแผนการออมเงิน
  • ทำรายการสิ่งของ
  • จัดตาราง To-Do List
💼

ในอนาคต (การทำงาน)

  • สร้างรายงานยอดขาย
  • วิเคราะห์ข้อมูลธุรกิจ
  • จัดทำงบประมาณ
  • บริหารจัดการโปรเจกต์
🔍

การเปิดโปรแกรมและเริ่มต้นใช้งาน

1

เปิดโปรแกรม Excel

คลิก Start → พิมพ์ค้นหา "Excel" → คลิกเปิดโปรแกรม

💡 หรือดับเบิลคลิกที่ไอคอน Excel บน Desktop / Taskbar
2

สร้างไฟล์ใหม่

หน้าจอ Start Screen จะปรากฏ → เลือก "Blank Workbook" เพื่อสร้างสมุดงานเปล่า

💡 สามารถเลือก Template สำเร็จรูปได้ เช่น ปฏิทิน, งบประมาณ, ตารางงาน
3

ป้อนข้อมูล

คลิกที่เซลล์ที่ต้องการ → พิมพ์ข้อมูล → กด Enter เพื่อยืนยัน

💡 กด Tab เพื่อเลื่อนไปคอลัมน์ถัดไป, Enter เลื่อนลงแถวถัดไป
4

บันทึกไฟล์

กด Ctrl + S → เลือกตำแหน่งที่เก็บ → ตั้งชื่อไฟล์ → กด Save

💡 ควรบันทึกบ่อยๆ เพื่อป้องกันข้อมูลสูญหาย! แนะนำทุก 5-10 นาที

ชนิดของข้อมูลใน Excel (Data Types)

Excel สามารถรับข้อมูลได้หลายชนิด ซึ่งจะส่งผลต่อการคำนวณ การจัดตำแหน่ง และการแสดงผล สิ่งสำคัญคือต้องเข้าใจว่าข้อมูลแต่ละชนิดมีพฤติกรรมต่างกัน

🔢

ตัวเลข (Number)

ข้อมูลตัวเลขที่สามารถนำมาคำนวณได้

ตัวอย่าง: 100, 3.14, -5, 0.85
📍 จัดชิดขวาอัตโนมัติ
⚠️ ตัวเลขที่ขึ้นต้นด้วย 0 (เช่น เลขบัตร ปชช.) ต้องกำหนดเป็น Text ก่อน
📝

ข้อความ (Text)

ข้อมูลที่เป็นตัวอักษร ไม่สามารถคำนวณได้

ตัวอย่าง: สมชาย, Hello, ม.4/1
📍 จัดชิดซ้ายอัตโนมัติ
💡 ถ้าพิมพ์ '0891234567 (ใส่ ' นำหน้า) Excel จะเก็บเป็น Text
📅

วันที่/เวลา (Date/Time)

ข้อมูลวันที่และเวลา สามารถคำนวณระยะห่างได้

ตัวอย่าง: 1/1/2025, 10:30 AM, 28 มิ.ย. 69
📍 จัดชิดขวาอัตโนมัติ
💡 Excel เก็บวันที่เป็นตัวเลข ดังนั้นสามารถ +/- วันได้!

การเรียงลำดับและกรองข้อมูล (Sort & Filter)

📊 การเรียงลำดับ (Sort)

ใช้จัดเรียงข้อมูลตามลำดับที่ต้องการ:

1. คลิกเซลล์ในคอลัมน์ที่ต้องการเรียง
2. ไปที่แท็บ Data
3. เลือก A→Z (น้อยไปมาก) หรือ Z→A (มากไปน้อย)
💡
ใช้ Custom Sort เพื่อเรียงหลายคอลัมน์ เช่น เรียงตามชั้นก่อน แล้วเรียงตามคะแนน

🔍 การกรองข้อมูล (Filter)

แสดงเฉพาะข้อมูลที่ตรงตามเงื่อนไข:

1. คลิกเซลล์ใดก็ได้ในตาราง
2. ไปที่แท็บ Data → Filter
3. คลิกลูกศร ▼ ที่หัวคอลัมน์
4. เลือก/ยกเลิกเลือกรายการที่ต้องการ
💡

ฟังก์ชันที่ใช้บ่อยที่สุด

ฟังก์ชัน คือ สูตรสำเร็จรูปที่ Excel เตรียมไว้ให้ ทำให้ไม่ต้องเขียนสูตรยาวๆ เอง

SUM หาผลรวม
=SUM(ช่วงเซลล์)
=SUM(A1:A10)รวมค่า A1 ถึง A10
=SUM(A1,B1,C1)รวม A1 + B1 + C1
AVERAGE หาค่าเฉลี่ย
=AVERAGE(ช่วงเซลล์)
=AVERAGE(B2:B30)เฉลี่ยคะแนนทั้งห้อง
=AVERAGE(B2:D2)เฉลี่ยคะแนน 3 วิชาของคนเดียว
MAX หาค่าสูงสุด
=MAX(ช่วงเซลล์)
=MAX(C2:C50)คะแนนสูงสุดของห้อง
MIN หาค่าต่ำสุด
=MIN(ช่วงเซลล์)
=MIN(C2:C50)คะแนนต่ำสุดของห้อง
COUNT นับจำนวนเซลล์ที่มีตัวเลข
=COUNT(ช่วงเซลล์)
=COUNT(A1:A100)นับจำนวนเซลล์ที่มีข้อมูลตัวเลข
=COUNTA(A1:A100)นับเซลล์ที่มีข้อมูลทุกชนิด (รวม Text)
IF สร้างเงื่อนไข (ถ้า...แล้ว...ไม่งั้น...)
=IF(เงื่อนไข, ค่าถ้าจริง, ค่าถ้าเท็จ)
=IF(A1>=50,"ผ่าน","ไม่ผ่าน")ถ้า ≥50 แสดง "ผ่าน"
=IF(B2>=80,"A",IF(B2>=70,"B",IF(B2>=60,"C","D")))ตัดเกรดอัตโนมัติ
COUNTIF นับจำนวนตามเงื่อนไข
=COUNTIF(ช่วง, เงื่อนไข)
=COUNTIF(D2:D50,"A")นับจำนวนคนที่ได้เกรด A
=COUNTIF(B2:B50,">=80")นับคนที่ได้คะแนน ≥80
SUMIF รวมค่าตามเงื่อนไข
=SUMIF(ช่วงเงื่อนไข, เงื่อนไข, ช่วงรวมค่า)
=SUMIF(A:A,"อาหาร",C:C)รวมค่าใช้จ่ายหมวด "อาหาร"
VLOOKUP ค้นหาข้อมูลในตาราง
=VLOOKUP(ค่าค้น, ตาราง, คอลัมน์ที่จะแสดง, ประเภทการค้น)
=VLOOKUP(A2,Sheet2!A:B,2,FALSE)ค้นชื่อจาก Sheet2 แสดงข้อมูลคอลัมน์ 2
💡 ใช้ FALSE (ค้นหาตรงกัน) เป็นหลัก | ค่าที่ค้นต้องอยู่คอลัมน์แรกสุดของตาราง
📎

การอ้างอิงเซลล์ (Cell Reference)

เมื่อคัดลอกสูตรไปเซลล์อื่น Cell Reference จะมีผลต่อการเปลี่ยนแปลงของสูตร

Relative Reference

A1, B2, C3

เปลี่ยนตามตำแหน่งที่ Copy ไป

Copy =A1+B1 ลง 1 แถว → =A2+B2

Absolute Reference

$A$1, $B$2

ล็อคไว้ ไม่เปลี่ยนเมื่อ Copy

Copy =$A$1*B1 ลง → =$A$1*B2

Mixed Reference

$A1, A$1

ล็อคเฉพาะ Row หรือ Column

$A1 = ล็อคคอลัมน์ | A$1 = ล็อคแถว
💡
เคล็ดลับ: กด F4 เพื่อสลับระหว่าง A1 → $A$1 → A$1 → $A1 → A1

🔧 เทคนิคขั้นสูงที่ใช้:

  • Data Validation: สร้าง Dropdown List เพื่อจำกัดตัวเลือกคำตอบ (เช่น มากที่สุด, มาก, ปานกลาง, น้อย, น้อยที่สุด)

  • กราฟ: สร้างกราฟแท่ง/วงกลมสรุปผลสำรวจ
  • Print Layout: จัดหน้าให้สวยงามสำหรับพิมพ์ส่งอาจารย์
